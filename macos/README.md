# macOS

Notes and prefs for this machine. Third-party apps are linked, not vendored.

## Screensaver

- **[Fliqlo](https://fliqlo.com/screensaver/)** — Flip-clock screensaver for macOS (and Windows).

### Install (macOS)

1. Download from [fliqlo.com/screensaver](https://fliqlo.com/screensaver/).
2. Open the `.saver` (or follow the site’s installer).
3. System Settings → Screen Saver → choose **Fliqlo**.

## Browsers

- **[Search](https://github.com/driceroland/Search)** — Small, fast WebKit browser for macOS (Office Commun).
- **[Helium](https://github.com/imputnet/helium)** — Private, fast, and honest web browser.

## Multi-device desk

- **[TwinDesk](https://github.com/InukaAsith/TwinDesk)** — Share screens, apps, files, clipboard, mouse/keyboard, calls, texts, and notifications across Mac, Windows, Linux, and Android. Free, open source, no account/cloud; works over Wi‑Fi, USB, Bluetooth, or Wi‑Fi Direct. Site: [twin-desk.vercel.app](https://twin-desk.vercel.app). macOS 13+ (Apple Silicon / Intel DMG).
- **[Beamer](https://github.com/kalkman-code/beamer)** — GPL-3.0 software KVM: share one keyboard, mouse/trackpad, and clipboard across Macs (13+, Apple Silicon/Intel), Windows 10/11, and Linux (experimental Flatpak) over your local network, in either direction; no account or cloud. Site: [kalkmancode.co.uk/beamer](https://kalkmancode.co.uk/beamer). Download from [releases](https://github.com/kalkman-code/beamer/releases/latest) (note: `brew install --cask beamer` is a different Softorino casting app).

## Menu bar utilities

- **[Maccy](https://github.com/p0deje/Maccy)** — Lightweight clipboard manager for macOS (history search, paste previous copies). Free, open source. Site: [maccy.app](https://maccy.app). Homebrew: `brew install --cask maccy`.
- **[Ice](https://github.com/jordanbaird/Ice)** — Powerful menu bar manager for macOS (hide/show items, notch-friendly layouts). Free, open source. Site: [icemenubar.app](https://icemenubar.app). macOS 14+. Homebrew: `brew install --cask jordanbaird-ice`.
- **[Vorssaint](https://github.com/vorssaint/vorssaint-utils)** — Free open-source macOS menu bar toolkit (volume mixer, system monitor, app switcher, window layout, clipboard history, snippets, uninstaller, and more). Install only the features you use; no account, no telemetry. Site: [vorssaint.com](https://vorssaint.com). Requires macOS 14+ Apple Silicon.

## Notch & Dynamic Island

- **[Sapphire](https://github.com/cshariq/Sapphire)** — All-in-one free open-source notch app for MacBooks (Now Playing, calendar, weather, file shelf, Nearby Share from Android, window snapping, lock-screen widgets, and more). Site: [sapphire-app.tech](https://sapphire-app.tech). Download: [releases](https://github.com/cshariq/Sapphire/releases/latest).
- **[Droppy](https://getdroppy.app/)** — Supercharged Dynamic Island for Mac (works with or without a notch): Live Activities, file tray, clipboard, Now Playing, 41 free Droplets (agents, meetings, cleaner, etc.). Paid one-time license; 3-day free trial. macOS 14+. Site: [getdroppy.app](https://getdroppy.app/). Homebrew: `brew install --cask droppy`.
- **[Coucou](https://github.com/louis-cfm/coucou)** — Tiny open-source companion in the Mac notch (and Windows/Linux top bar) that watches AI coding agents (Claude Code, Codex, Cursor, Gemini CLI, Antigravity, and more): approve permissions, live diffs, chat, plus Flow dictation and call notetaker. Also on iPhone/Android. Free, MIT. macOS 15+. Site: [louis-cfm.github.io/coucou](https://louis-cfm.github.io/coucou/). Download: [releases](https://github.com/louis-cfm/coucou/releases/latest).

## Mouse & scrolling

- **[Mos](https://github.com/Caldis/Mos)** — Smooth mouse scrolling on macOS and set scroll direction independently (trackpad-like wheel). Free, open source. Site: [mos.caldis.me](http://mos.caldis.me). Homebrew: `brew install --cask mos`.

## Desk gestures

- **[Holo](https://github.com/JustinGamer191/Holo)** — Tap your desk; your Mac responds. Experimental native utility that turns the area around a MacBook into four assignable tap zones (mic-based, local). Actions: Shortcut, app, URL, shell, screenshot, etc. macOS 14+. Landing: [justingamer191.github.io/Holo](https://justingamer191.github.io/Holo/). Releases: [github.com/JustinGamer191/Holo/releases](https://github.com/JustinGamer191/Holo/releases).

## Displays

- **[BetterDisplay](https://github.com/waydabber/BetterDisplay)** — Unlock Mac displays: flexible HiDPI scaling, XDR/HDR brightness, virtual screens, DDC control, image adjustments, PIP/streaming, EDID override. Site/guide: [betterdisplay.pro](https://betterdisplay.pro).
- **[MonitorControl](https://github.com/MonitorControl/MonitorControl)** — Control external display brightness & volume from the Mac (keyboard shortcuts, native OSDs) as if it were an Apple Display. Free, open source. Site: [monitorcontrol.app](https://monitorcontrol.app). Homebrew: `brew install --cask monitorcontrol`.

## Dock

- **[docktor](https://docktorapp.com/)** — Free notarized macOS utility: live Dock window previews on hover, optional Cmd+Tab with thumbnails, plus glass widgets beside the Dock (Music, Calendar, Weather, System Stats, Device Batteries). No account. Site: [docktorapp.com](https://docktorapp.com/).

## Legacy Macs

- **[OpenCore Legacy Patcher](https://github.com/dortania/OpenCore-Legacy-Patcher)** — Run modern macOS (Big Sur through Sequoia/Tahoe) on Macs Apple no longer supports, via OpenCore + Lilu. Also unlocks features (e.g. Sidecar, AirPlay to Mac) on some native Macs. Guide: [dortania.github.io/OpenCore-Legacy-Patcher](https://dortania.github.io/OpenCore-Legacy-Patcher/).

## Audio

- **[BetterAudio](https://github.com/rokartur/BetterAudio)** — Master your Mac’s audio (menu bar / system audio control). Free core + optional support license. macOS 14.6+. Site: [betteraudio.pro](https://betteraudio.pro). Homebrew: `brew install --cask betteraudio`.

## Battery

- **[AlDente](https://github.com/AppHouseKitchen/AlDente-Battery_Care_and_Monitoring)** — Menu bar charge limiter to prolong MacBook battery life (set max charge %, discharge while plugged in). Free + Pro. macOS 12+. Site: [apphousekitchen.com](https://apphousekitchen.com/). Homebrew: `brew install --cask aldente`.

## Remote desktop

Cross-platform remote access / screen sharing (links, not vendored).

- **[TeamViewer](https://www.teamviewer.com/)** — Remote control and support across desktop and mobile. Homebrew: `brew install --cask teamviewer`.
- **[AnyDesk](https://anydesk.com/)** — Lightweight remote desktop. Homebrew: `brew install --cask anydesk`.
- **[NoMachine](https://www.nomachine.com/)** — NX-based remote desktop (also [ES](https://www.nomachine.com/es/)). Homebrew: `brew install --cask nomachine`.
- **[Parsec](https://parsec.app/)** — Low-latency remote desktop / game streaming. Homebrew: `brew install --cask parsec`.
- **[Jump Desktop](https://jumpdesktop.com/)** — RDP/VNC client (Mac/iOS). Homebrew: `brew install --cask jump-desktop` (host: `jump-desktop-connect`).
- **[Screens 5](https://apps.apple.com/es/app/screens-5-vnc-escritorio/id1663047912)** — VNC remote desktop for Mac (Edovia). App Store.

## Terminals

- **[Warp](https://github.com/warpdotdev/warp)** — Agentic development environment born out of the terminal (Rust). Site: [warp.dev/terminal](https://www.warp.dev/terminal). Homebrew: `brew install --cask warp`.
- **[Ghostty](https://github.com/ghostty-org/ghostty)** — Fast, feature-rich cross-platform terminal with native UI and GPU acceleration. Site: [ghostty.org](https://ghostty.org/). Homebrew: `brew install --cask ghostty`.
- **[Alacritty](https://github.com/alacritty/alacritty)** — Cross-platform, GPU-accelerated OpenGL terminal emulator. Homebrew: `brew install --cask alacritty`.
- **[WezTerm](https://github.com/wezterm/wezterm)** — GPU-accelerated cross-platform terminal emulator and multiplexer (Rust). Site: [wezterm.org](https://wezterm.org/). Homebrew: `brew install --cask wezterm`.
- **[Kitty](https://github.com/kovidgoyal/kitty)** — Fast, feature-rich, GPU-based cross-platform terminal emulator. Site: [sw.kovidgoyal.net/kitty](https://sw.kovidgoyal.net/kitty/). Homebrew: `brew install --cask kitty`.
- **[cmux](https://github.com/manaflow-ai/cmux)** — Ghostty-based macOS terminal with vertical tabs and notifications for AI coding agents. Site: [cmux.dev](https://www.cmux.dev/). Homebrew: `brew install --cask cmux`.

## File converters

- **[Tangerine](https://tangerineformac.com/)** — Zero-click offline file converter for Mac (drag + Shift to convert images, video, audio, documents, archives locally; no uploads). Mac App Store.
- **[Filee](https://github.com/KnifeLemon/Filee)** — **Recommended open-source alternative to Tangerine.** Free offline converter for 263 formats (images, PDF, Office, HWP, video, audio, e-books, archives) via drag-and-drop; no upload, no Office required. macOS 13+ (preview), Windows, Linux. Site: [filee.sh](https://filee.sh). Download: [releases](https://github.com/KnifeLemon/Filee/releases/latest).

## PDF tools

- **[Stirling PDF](https://github.com/Stirling-Tools/Stirling-PDF)** — Open-core, self-hostable PDF toolbox (~96k★): edit, merge, split, convert, OCR, sign, compress, redact, and 50+ more operations, processed locally. Desktop app for macOS/Windows/Linux or Docker/web server. Site: [stirling.com](https://stirling.com/). Homebrew: `brew install --cask stirling-pdf`.

## Utilities

- **[AppCleaner](https://freemacsoft.net/appcleaner/)** — Thorough Mac app uninstaller (removes leftovers). Free. Homebrew: `brew install --cask appcleaner`.
- **[Mole](https://github.com/tw93/mole)** — Free open-source Mac cleaner / optimizer (deep clean, smart uninstall, disk analyzer, live status). CLI (`mo`) plus native Mac and Windows apps. Site: [mole.fit](https://mole.fit). Homebrew (CLI): `brew install mole`.
- **[Mac Sai](https://github.com/iliyami/MacSai)** — Free open-source Mac cleaner, optimizer, and malware scanner (Apple-notarized CleanMyMac alternative; Swift 6 / SwiftUI). Site/repo: [github.com/iliyami/MacSai](https://github.com/iliyami/MacSai). Homebrew: `brew install --cask mac-sai`.
- **[neofetch](https://github.com/dylanaraps/neofetch)** — CLI system-info banner (bash). Repo archived; no longer in Homebrew core. Maintained alternative: **[fastfetch](https://github.com/fastfetch-cli/fastfetch)** — `brew install fastfetch`.

## Smart TV

- **[CleanYourTV](https://github.com/Gathin23/cleanyourtv)** — Debloat Android / Google / Fire TV over Wi‑Fi (ADB) and get an Apple TV–style home; no root, reversible. Site: [cleanyour.tv](https://cleanyour.tv).
