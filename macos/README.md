# macOS

Notes and prefs for this machine. Third-party apps are linked, not vendored.

## Screensaver

- **[Fliqlo](https://fliqlo.com/screensaver/)** — Flip-clock screensaver for macOS (and Windows).

### Install (macOS)

1. Download from [fliqlo.com/screensaver](https://fliqlo.com/screensaver/).
2. Open the `.saver` (or follow the site’s installer).
3. System Settings → Screen Saver → choose **Fliqlo**.

## Browsers

- **[Search](https://github.com/driceroland/Search)** — Small, fast WebKit browser for macOS (Office Commun).
- **[Helium](https://github.com/imputnet/helium)** — Private, fast, and honest web browser.

## Multi-device desk

- **[TwinDesk](https://github.com/InukaAsith/TwinDesk)** — Share screens, apps, files, clipboard, mouse/keyboard, calls, texts, and notifications across Mac, Windows, Linux, and Android. Free, open source, no account/cloud; works over Wi‑Fi, USB, Bluetooth, or Wi‑Fi Direct. Site: [twin-desk.vercel.app](https://twin-desk.vercel.app). macOS 13+ (Apple Silicon / Intel DMG).

## Menu bar utilities

- **[Vorssaint](https://github.com/vorssaint/vorssaint-utils)** — Free open-source macOS menu bar toolkit (volume mixer, system monitor, app switcher, window layout, clipboard history, snippets, uninstaller, and more). Install only the features you use; no account, no telemetry. Site: [vorssaint.com](https://vorssaint.com). Requires macOS 14+ Apple Silicon.

## Displays

- **[BetterDisplay](https://github.com/waydabber/BetterDisplay)** — Unlock Mac displays: flexible HiDPI scaling, XDR/HDR brightness, virtual screens, DDC control, image adjustments, PIP/streaming, EDID override. Site/guide: [betterdisplay.pro](https://betterdisplay.pro).

## Legacy Macs

- **[OpenCore Legacy Patcher](https://github.com/dortania/OpenCore-Legacy-Patcher)** — Run modern macOS (Big Sur through Sequoia/Tahoe) on Macs Apple no longer supports, via OpenCore + Lilu. Also unlocks features (e.g. Sidecar, AirPlay to Mac) on some native Macs. Guide: [dortania.github.io/OpenCore-Legacy-Patcher](https://dortania.github.io/OpenCore-Legacy-Patcher/).

## Battery

- **[AlDente](https://github.com/AppHouseKitchen/AlDente-Battery_Care_and_Monitoring)** — Menu bar charge limiter to prolong MacBook battery life (set max charge %, discharge while plugged in). Free + Pro. macOS 12+. Site: [apphousekitchen.com](https://apphousekitchen.com/). Homebrew: `brew install --cask aldente`.
