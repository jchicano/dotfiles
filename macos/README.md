# macOS

Notes and prefs for this machine. Third-party apps are linked, not vendored.

## Screensaver

- **[Fliqlo](https://fliqlo.com/screensaver/)** — Flip-clock screensaver for macOS (and Windows).

### Install (macOS)

1. Download from [fliqlo.com/screensaver](https://fliqlo.com/screensaver/).
2. Open the `.saver` (or follow the site’s installer).
3. System Settings → Screen Saver → choose **Fliqlo**.
