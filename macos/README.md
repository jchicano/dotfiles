# macOS

Notes and prefs for this machine. Third-party apps are linked, not vendored.

## Screensaver

- **[Fliqlo](https://fliqlo.com/screensaver/)** — Flip-clock screensaver for macOS (and Windows).

### Install (macOS)

1. Download from [fliqlo.com/screensaver](https://fliqlo.com/screensaver/).
2. Open the `.saver` (or follow the site’s installer).
3. System Settings → Screen Saver → choose **Fliqlo**.

## Browsers

- **[Search](https://github.com/driceroland/Search)** — Small, fast WebKit browser for macOS (Office Commun).
- **[Helium](https://github.com/imputnet/helium)** — Private, fast, and honest web browser.

## Multi-device desk

- **[TwinDesk](https://github.com/InukaAsith/TwinDesk)** — Share screens, apps, files, clipboard, mouse/keyboard, calls, texts, and notifications across Mac, Windows, Linux, and Android. Free, open source, no account/cloud; works over Wi‑Fi, USB, Bluetooth, or Wi‑Fi Direct. Site: [twin-desk.vercel.app](https://twin-desk.vercel.app). macOS 13+ (Apple Silicon / Intel DMG).
